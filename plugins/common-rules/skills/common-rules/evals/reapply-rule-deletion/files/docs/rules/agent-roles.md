# 역할 분담

- 코드·테스트·설정 코드는 워커가 쓴다. 오케스트레이터는 한 줄도 직접 편집하지 않는다. <!-- R-ROLE-01 -->
- 사용자가 "워크트리로 진행하자"고 하면 이 세션이 Orca 워크트리로 옮겨 그 작업을 직접 구현한다. <!-- R-ROLE-10 기존 -->
  - 이때도 구현 커밋 뒤에 리뷰 워커의 `succeeded`를 받아야 통과다. 자기 재실행은 독립 증거가 아니다. <!-- R-ROLE-10 -->
- 감독이 필요 없는 작업에는 orchestration 추적 명령을 쓰지 않는다. <!-- R-ROLE-06 -->
